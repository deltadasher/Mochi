# Mochi · Medal-inspired native UI

The user requested a Medal-style redesign. Reference inspected: the Library
screenshot in Medal's official Getting Started guide:
https://support.medal.tv/support/solutions/articles/48000959661/

Borrow the dark navigation rail, persistent compact recording toolbar, and dense
landscape thumbnail library with duration overlays and local-storage metadata.
Keep Mochi's own name. Warm amber marks actions and selection; lime marks active
recording. Use crisp typography, restrained borders, and minimal motion.

Audio has its own page with explicit input selection, a live dBFS meter, microphone
test, voice gain, configurable phrase, and in-memory recognition feedback. Clip
controls stay reachable across pages. Local playback, search, sorting, and favorites
are functional. Do not add decorative social/cloud features that the app cannot do.

Inspect at 1180×800 and 950×700; audio settings scroll at small window heights.

## Visual refinement

The user requested a proper logo and removal of unnecessary text. Keep the approved
Medal-inspired structure, but remove marketing copy, duplicate instructions, technical
specifications from the library, and redundant status lines. Use a responsive grid,
short time-based clip titles, and a compact recording toolbar with microphone status.
Routine confirmations disappear after five seconds; errors remain visible.

The custom vector mark combines a cat silhouette with a negative-space play button.
`assets/mochi.svg` is the transparent mark; `assets/mochi-app.svg` is the app icon.
Use amber for the mark and primary actions, warm white for the wordmark, and a
consistent stroke icon set for navigation. Explanations live in relevant tooltips.
